## RESTful API Node Server monitoring project

This project is a REST API build with Node.js and expressjs. It can be used with Postgres using Sequelize ORM.

## Requirements

- [Node v14.19.1+](http://nodejs.org/)

- [Express](https://npmjs.com/package/express)

- [Sequelize](https://www.npmjs.com/package/sequelize)

- [Yup](https://www.npmjs.com/package/yup)

- [Jsonwebtoken](https://www.npmjs.com/package/jsonwebtoken)

- [jwt-redis](https://www.npmjs.com/package/jwt-redis)

- redis-server

```sh
sudo apt-get install redis-server
sudo service redis-server status
```

( The output will be: `redis-server is running`)

## Installation

Clone the repository with `git clone ssh://git@gitlab.paypos.tn:2208/borne/api-monitoring.git`

Install the dependencies and devDependencies and start the server.

```sh
cd api-monitoring
npm i
node server.js
```
